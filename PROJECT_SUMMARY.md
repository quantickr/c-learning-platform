# 🎓 C Learning Platform - Сводка

## ✅ Что создано

Полноценная интерактивная обучающая платформа по основам языка C.

### 📦 Основные компоненты

1. **Главная страница** (`/`)
   - Приветствие и описание курса
   - Навигация на теорию и задачи
   - Информация о содержании

2. **Раздел теории** (`/theory`)
   - 6 теоретических разделов с примерами
   - Подсветка синтаксиса кода
   - Боковая навигация
   - Markdown рендеринг

3. **Список задач** (`/tasks`)
   - 15 задач, сгруппированных по типам
   - Фильтрация по категориям
   - Цветовая кодировка типов

4. **Страница задачи** (`/tasks/[id]`)
   - Описание задачи с примерами
   - Встроенный редактор кода (Monaco Editor)
   - Автоматическая проверка с тестами
   - Подсказки для сложных задач
   - Навигация между задачами

5. **API для компиляции** (`/api/compile`)
   - Интеграция с Judge0 API
   - Компиляция и запуск C кода
   - Обработка ошибок


Откройте: http://localhost:3000

### ⚙️ Настройка API (опционально)

Для работы автоматической проверки:

1. Зарегистрируйтесь на https://rapidapi.com/
2. Подпишитесь на Judge0 CE API (Free: 50 запросов/день)
3. Добавьте ключ в `.env.local`:
   ```
   RAPIDAPI_KEY=ваш_ключ
   ```
4. Перезапустите сервер

Без API ключа сайт работает, но проверка кода недоступна.

### 📊 Система тестирования

Каждая задача включает:
- **Базовые тесты** - из примеров в условии
- **Граничные случаи** - ноль, отрицательные числа
- **Крайние значения** - большие числа, минимумы/максимумы
- **Специальные случаи** - уникальные для каждой задачи

Результаты показывают:
- ✅/❌ Статус теста
- 📥 Входные данные
- 📤 Ожидаемый результат
- 📝 Фактический результат
- ⚠️ Ошибки компиляции/выполнения

### 🎯 Особые задачи

**Задача №11 (Високосный год)** - содержит подвох:
- Год високосный если: (делится на 4 И НЕ на 100) ИЛИ (делится на 400)
- 2000 ✅ (на 400)
- 1900 ❌ (на 100, но не на 400)
- 2024 ✅ (на 4, не на 100)

**Задача №9 (Простые числа)** - требует понимания:
- 1 не является простым числом
- Если простых нет, вернуть 0.0
