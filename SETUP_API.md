# Настройка Judge0 API для проверки кода

## Получение API ключа

Для работы автоматической проверки кода C необходим API ключ от Judge0.

### Шаг 1: Регистрация на RapidAPI

1. Перейдите на [RapidAPI](https://rapidapi.com/)
2. Зарегистрируйтесь или войдите в аккаунт

### Шаг 2: Подписка на Judge0 CE

1. Перейдите на страницу [Judge0 CE API](https://rapidapi.com/judge0-official/api/judge0-ce)
2. Нажмите кнопку "Subscribe to Test"
3. Выберите план:
   - **Basic (Free)**: 50 запросов/день
   - **Pro**: 100 запросов/день ($5/месяц)
   - **Ultra**: 1000 запросов/день ($10/месяц)
   - **Mega**: 10000 запросов/день ($25/месяц)

### Шаг 3: Получение ключа

1. После подписки вернитесь на страницу API
2. В разделе "Code Snippets" справа найдите заголовок `X-RapidAPI-Key`
3. Скопируйте ваш ключ (строка вида `abcd1234...`)

### Шаг 4: Настройка проекта

1. Откройте файл `.env.local` в корне проекта
2. Замените `your_rapidapi_key_here` на ваш ключ:

```
RAPIDAPI_KEY=ваш_настоящий_ключ_здесь
```

3. Сохраните файл
4. Перезапустите сервер разработки:

```bash
npm run dev
```

## Альтернативный вариант: Локальная установка Judge0

Если вы не хотите использовать RapidAPI, можно развернуть Judge0 локально через Docker:

```bash
git clone https://github.com/judge0/judge0.git
cd judge0
docker-compose up -d
```

Затем в файле `app/api/compile/route.ts` измените URL на:
```typescript
const response = await fetch('http://localhost:2358/submissions?base64_encoded=false&wait=true', {
  // ...
});
```

## Проверка работы

1. Откройте сайт: http://localhost:3000
2. Перейдите в раздел "Задачи"
3. Выберите любую задачу
4. Напишите решение и нажмите "Запустить тесты"
5. Если API настроен правильно, вы увидите результаты проверки

## Устранение проблем

### Ошибка "Сервис компиляции временно недоступен"

- Проверьте правильность API ключа в `.env.local`
- Убедитесь, что не превышен лимит запросов
- Проверьте подключение к интернету

### Ошибка 401 Unauthorized

- API ключ неверный или не активирован
- Перепроверьте подписку на RapidAPI

### Ошибка 429 Too Many Requests

- Превышен лимит запросов вашего плана
- Подождите или обновите план на более высокий
