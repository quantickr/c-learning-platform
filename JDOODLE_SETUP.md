# Настройка JDoodle API

JDoodle предоставляет **200 бесплатных запросов в день** для компиляции кода.

## 🔑 Получение API ключей

### 1. Регистрация

Зайдите на: https://www.jdoodle.com/compiler-api

Нажмите **"Subscribe"** и заполните форму:
- Email
- Имя
- Для чего будете использовать (Education/Learning)

### 2. Получение ключей

После регистрации на email придёт письмо с:
- **Client ID** (например: `abc123def456`)
- **Client Secret** (например: `xyz789uvw012pqr345`)

### 3. Добавление в проект

#### Локально (.env.local):
```env
JDOODLE_CLIENT_ID=ваш_client_id
JDOODLE_CLIENT_SECRET=ваш_client_secret
```

#### На Railway:
1. Variables → New Variable
2. Добавьте две переменные:
   - `JDOODLE_CLIENT_ID` = ваш client id
   - `JDOODLE_CLIENT_SECRET` = ваш secret

#### На Render:
1. Environment → Add Environment Variable
2. Добавьте обе переменные

## 📊 Лимиты

**Бесплатный план:**
- ✅ 200 запросов/день
- ✅ Достаточно для учебных целей
- ✅ Навсегда бесплатно

**Платные планы (если нужно больше):**
- Standard: $7/месяц - 2000 запросов/день
- Pro: $15/месяц - 10000 запросов/день

## 🧪 Тестирование

После добавления ключей перезапустите приложение:

```bash
npm run dev
```

Откройте любую задачу и попробуйте запустить тесты!

## ⚠️ Важно

- НЕ публикуйте ключи в GitHub
- Используйте только через переменные окружения
- Один аккаунт = один email

## 🆘 Если ключи не работают

1. Проверьте email - возможно письмо в спаме
2. Убедитесь что скопировали ключи полностью
3. Перезапустите сервер после добавления переменных
4. Проверьте что переменные называются точно:
   - `JDOODLE_CLIENT_ID`
   - `JDOODLE_CLIENT_SECRET`

---

**Альтернатива:** Если не хотите регистрироваться, можно использовать демо-ключи, но они сильно ограничены (несколько запросов в день).
