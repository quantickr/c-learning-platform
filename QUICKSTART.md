# Быстрый старт

## 🎯 Что это?

Интерактивная обучающая платформа по основам языка C с автоматической проверкой кода. 15 задач с тестами, теоретический материал, встроенный редактор кода.

## ⚡ Быстрый запуск (без API)

Если вы хотите просто посмотреть интерфейс без настройки API:

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

**Примечание**: Без API ключа кнопка "Запустить тесты" не будет работать. Для полной функциональности нужен Judge0 API (см. SETUP_API.md).

## 🚀 Полная настройка (с проверкой кода)

### 1. Установка

```bash
cd ~/c-learning-platform
npm install
```

### 2. Получение API ключа

1. Зарегистрируйтесь на https://rapidapi.com/
2. Подпишитесь на Judge0 CE API (есть бесплатный план: 50 запросов/день)
3. Скопируйте ваш API ключ

### 3. Настройка

Создайте `.env.local` и добавьте ключ:

```
RAPIDAPI_KEY=ваш_ключ_здесь
```

### 4. Запуск

```bash
npm run dev
```

Откройте http://localhost:3000

## 📖 Как использовать

### Изучение теории

1. Главная страница → "Теория"
2. Читайте объяснения с примерами кода
3. Все примеры с подсветкой синтаксиса

### Решение задач

1. Главная страница → "Задачи"
2. Выберите задачу
3. Напишите код в редакторе
4. Нажмите "Запустить тесты"
5. Посмотрите результаты

### Пример решения задачи №1 (Чётное или нечётное)

```c
int is_even(int n) {
    if (n % 2 == 0) {
        return 1;  // чётное
    } else {
        return 0;  // нечётное
    }
}
```

Или компактнее:

```c
int is_even(int n) {
    return (n % 2 == 0) ? 1 : 0;
}
```

## 🐛 Решение проблем

**Не работает проверка кода?**
- Проверьте API ключ в `.env.local`
- Убедитесь, что подписаны на Judge0 API

**Тесты не проходят?**
- Проверьте формат вывода (должен точно совпадать)
- Обратите внимание на русский язык в выводе
- Читайте описание теста

**Медленная проверка?**
- Это нормально - код компилируется и запускается на удалённом сервере
- Каждый тест выполняется отдельно

## 💡 Советы по решению задач

1. **Читайте примеры** - они показывают формат ввода-вывода
2. **Смотрите подсказки** - есть у сложных задач
3. **Тестируйте граничные случаи** - ноль, отрицательные числа
4. **Используйте правильный тип** - int vs double
5. **Проверяйте русский язык** - "понедельник", а не "Monday"
