# Настройка AI помощника (Ollama + Qwen)

Платформа включает AI помощника на базе локальной модели Qwen 2.5 Coder для помощи студентам с задачами.

## Установка Ollama

### macOS / Linux

```bash
# Скачайте и установите с официального сайта
# https://ollama.com

# Или через curl
curl -fsSL https://ollama.com/install.sh | sh
```

### Windows

Скачайте установщик с https://ollama.com/download

## Установка модели Qwen 2.5 Coder

```bash
# Запустите Ollama сервер
ollama serve

# В другом терминале установите модель
ollama pull qwen2.5-coder:latest
```

## Проверка работы

```bash
# Проверьте, что модель установлена
ollama list

# Должна появиться строка:
# qwen2.5-coder:latest  ...  ...  ...

# Проверьте работу модели
ollama run qwen2.5-coder:latest "Привет!"
```

## Запуск платформы

После установки Ollama и модели:

```bash
# Убедитесь, что Ollama работает
ollama serve

# В другом терминале запустите платформу
npm run dev
```

## Как работает AI помощник

1. На странице задачи появляется кнопка 💬 в правом нижнем углу
2. Нажмите на неё, чтобы открыть чат
3. Задавайте вопросы о задаче, синтаксисе C или просите подсказки
4. Модель отвечает на русском языке и помогает, не давая полного решения

## Конфигурация

В файле `.env.local`:

```env
OLLAMA_URL=http://localhost:11434
```

Можно изменить, если Ollama запущен на другом порту или удалённом сервере.

## Альтернативные модели

Можно использовать другие модели Ollama:

```bash
# Более лёгкая модель (быстрее, но менее умная)
ollama pull qwen2.5-coder:7b

# Более мощная модель (медленнее, но умнее)
ollama pull qwen2.5-coder:32b
```

Измените модель в `app/api/chat/route.ts`:
```typescript
model: 'qwen2.5-coder:7b',  // или другая модель
```

## Требования к системе

- **RAM**: минимум 8 ГБ (рекомендуется 16 ГБ для больших моделей)
- **Диск**: ~5 ГБ свободного места для модели
- **CPU/GPU**: работает на CPU, но GPU ускоряет генерацию

## Troubleshooting

### Ошибка "Ollama недоступен"

1. Проверьте, что Ollama запущен: `ollama serve`
2. Проверьте порт: `curl http://localhost:11434`
3. Проверьте модель: `ollama list`

### Медленные ответы

1. Используйте меньшую модель (7b вместо latest)
2. Закройте другие приложения для освобождения RAM
3. Если есть GPU, убедитесь что Ollama его использует

### Модель отвечает не на русском

Qwen 2.5 Coder поддерживает русский язык. Если ответы на английском, попробуйте переустановить модель:

```bash
ollama rm qwen2.5-coder:latest
ollama pull qwen2.5-coder:latest
```

## Без AI помощника

Если не хотите использовать AI помощника, просто не устанавливайте Ollama. Платформа будет работать без него, кнопка чата просто покажет сообщение об отсутствии модели.
